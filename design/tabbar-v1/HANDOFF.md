# 底栏 v1 交接（Qian 2026-11-20 选定：方向 A +「今日」）

设计已更新，还没实现。由 Engineer 实现，Designer 做一次轻量核对。可随 1.0.11 热更新，不必为这一项单独重打包（若工程判断必须打新包再另说）。

## 改什么

- 底栏三个 Tab 对调并改名，从左到右：**今日 / 对话 / 知识库**。
- 打开 App **默认停在「今日」**（取代原先默认进对话）。
- 「今日」打开的是主动服务首页（已批准的沉浸版 v8），不是新模块。
- 换新图标（方向 A），换标签颜色：选中是墨色粗体，**文字不用橙色**。
- 底栏背景跟随系统：浅色奶白 `#F3EFE7`，深色 `#171614`。即使上面是深色沉浸卡，浅色模式仍用奶白底栏。只有顶部 1px 分隔线，不加阴影，底部手势区约 20dp **只留空，不画中间横条**。
- 详细尺寸、首页排序和状态见同目录 `SPEC.md`。主设计文档已同步，见 `docs/DESIGN.md` 第 4 节。

## 图标

实现只用 `icons/a/`。`icons/b/` 是设计过程中的备选，不要接进 App。

文件名里的 `discover` 对应文案「今日」，不要改文件名，也不要在界面上写「发现」。

```
tabbar-v1/icons/a/discover-unselected.svg
tabbar-v1/icons/a/discover-selected.svg
tabbar-v1/icons/a/chat-unselected.svg
tabbar-v1/icons/a/chat-selected.svg
tabbar-v1/icons/a/library-unselected.svg
tabbar-v1/icons/a/library-selected.svg
```

- 画在 24 网格上，描边 1.75，圆头圆角。未选 / 选中共用外形。
- SVG 主体用 `currentColor`，橙色写死 `#FF6A2B`。
- 未选：`currentColor` 设成 `--text-3`（浅 `#736D62`，深 `#9A9386`），画线。
- 选中：`currentColor` 设成 `--text-1`（浅 `#1C1B19`，深 `#EDE8DF`），填墨色，并各留一处活力橙：今日=火花，对话=短圆角尾巴（贴在气泡左下角，不要再做成向外伸出的长尾巴），知识库=书签。
- 选中「对话」的两只眼睛是挖空（`fill-rule: evenodd`），透出底栏颜色，浅色、深色用同一份 SVG。

## 颜色与尺寸（C1 token）

| 项目 | 值 |
|---|---|
| 底栏内容区 | 56dp + 约 20dp 安全区（空） |
| 图标 | 24dp |
| 标签 | 12px / 行高 16；选中 700，未选 400。雅黑没有中字重，不要写 500/600 |
| 图标与标签间距 | 4dp |
| 顶部分隔 | 1px `--line`（浅 `#E3DDD1`，深 `#34312C`） |
| 底栏背景 | `--bg` 浅 `#F3EFE7`，深 `#171614` |
| 选中填充 / 选中字 | `--text-1` |
| 未选线 / 未选字 | `--text-3` |
| 活力橙（仅图形和未读点） | `--accent` `#FF6A2B` |
| 按下弱底（可选） | `--fill` |

**文字不用 `--accent` 或 `--accent-ink`。** 橙色只出现在选中图标的那一个点上，以及未读点。

未读：图标右上 8dp 活力橙圆点，不显示数字，外边留 2dp 底栏色描边。已经停在该 Tab 时不要再打点。

对话页、主动服务沉浸页里底栏继续隐藏；返回后还在原来的位置。

## 「今日」首页

视觉仍按 v8，不改卡片结构。

- 当天新内容排最前，顺序：AI Daily Signal → Daily Spoken English → AI Infra Learning 新课；复习卡在后；看过的卡下次打开往后沉。不要把旧卡冒充新内容。
- 当天新内容都看过之后，先出「今天已看完」收尾卡，写明下一条大约什么时候到，并标明这是示例或估算（「示例时间，实际以各 bot 更新为准」）。下面仍可回看。
- 第一次打开或还没有真实数据时，样例卡左上角标「样例」。接上真实数据后不要再用样例冒充当天内容。

## 知识库

与对话页同一套缓存规则：有缓存就先显示，不要全屏加载或先白屏；后台同步，只有一行「同步中 / 未同步」。App 启动后可在后台预加载，避免第一次点开才去取远端。（启动预加载若已在 1.0.11 热更新里做了，保持即可。）

## 核对标准（只做一次轻量核对）

- 顺序是今日 / 对话 / 知识库，打开默认停在今日。
- 浅色、深色底栏：奶白或墨底，只有顶部分隔线；选中是墨色填充 + 一处活力橙；标签不是橙色。
- 三个图标在 24dp 下大小接近，火花、短尾巴、书签能认出来；对话尾巴是短圆角，不是向外凸出一截。
- 「今日」有新内容且当前不在这个 Tab 时，右上有 8dp 橙点。
- 知识库首次进入：有缓存就先画出内容，只有一行同步提示。
- 样例卡带「样例」标签；不要把旧内容说成新的。
